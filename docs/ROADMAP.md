- landing page;
- mock confession feed;
- responsive design;

- Next.js frontend;
- wallet authentication;
- PostgreSQL;
- API;
- confession CRUD;
- reactions;
- whispers;
- reports;
- moderator dashboard;

- content-addressed storage;
- encrypted payload strategy;
- better anti-spam;
- feed ranking;
- observability;
- backups;
- security review;
- privacy policy;
- community guidelines.

## Phase 2 — Privacy

- anonymous credentials;
- relayed blockchain transactions;
- stronger separation of wallet and public action;
- privacy-preserving rate limits;
- ZK proofs where justified.
